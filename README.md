# 🚀 네이버 → 티스토리 자동 마이그레이션 프로그램 (SEO Alt 텍스트 지원)

네이버 블로그의 글(텍스트 및 원본 크기 이미지)을 크롤링하여 티스토리 에디터에 자동으로 붙여넣고, 검색엔진 최적화(SEO)를 위한 이미지 대체 텍스트(Alt Text)까지 자동으로 주입해 주는 파이썬 자동화 프로그램입니다.

---

## 🛠️ 1. 사전 준비물 (필수 설치)

컴퓨터에 **Python**이 설치되어 있어야 합니다. (Python 3.8 이상 권장)

### 패키지 설치 방법
명령 프롬프트(CMD)나 터미널을 열고, 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력하여 필요한 라이브러리를 한 번에 설치하세요.

```bash
pip install -r requirements.txt
```

---

## 🚀 2. 프로그램 실행 방법

1. 터미널 또는 명령 프롬프트에서 프로그램 파일을 실행합니다.
   ```bash
   python naver_to_tistory.py
   ```
2. 프로그램 창이 실행되면 **[1단계: 브라우저 열기 (수동 로그인)]** 버튼을 누릅니다.
3. 열린 크롬 창에서 **티스토리 계정으로 로그인**을 완료합니다.
4. 네이버 아이디를 입력한 뒤 **[최근 글 목록 불러오기]**를 누르고, 마이그레이션할 글을 **더블클릭**하거나 네이버 글 번호를 직접 입력합니다.
5. 본인의 **티스토리 주소명**(`주소명.tistory.com`에서 앞부분)을 입력합니다.
6. **[글 가져오기 및 작성 (사진 포함)]** 버튼을 누르면 자동으로 텍스트, 원본 크기 이미지, SEO 대체 텍스트가 순서대로 입력됩니다.

---

## ✨ 주요 기능
- **원본 크기 사진 보존**: 네이버 썸네일 대신 고해상도 원본 이미지 주소를 찾아 다운로드하여 업로드합니다.
- **캡션(설명란) 충돌 방지**: 사진이 들어간 후 자동으로 커서가 캡션 밖으로 빠져나오도록 처리되어 본문 글이 꼬이지 않습니다.
- **SEO 대체 텍스트(Alt) 자동 삽입**: `"[글 제목] - 사진 X"` 형태로 이미지에 Alt 태그를 강제 주입하여 검색엔진 노출에 유리하게 설계되었습니다.
